3 Analysis

Complete-case & sensitivity

A complete-pair estimate carries no missing-data assumption. Sensitivity analyses are reported separately, each with its assumption stated, and are never pooled into the complete-case result.

Run an analysis

Inputs are hashed before any arithmetic

Missing-contrast bounds apply only to the sensitivity bound, never to the complete-case estimate. Leave them empty to use the outcome's full plausible range, which is the widest declared bound and is reported as such.

Runs & recovery

An interrupted run keeps its stage checkpoints, each bound to an input hash. “Resume” re-hashes the current inputs and reuses only matching checkpoints; if the observations were corrected or the plan replaced in between, it refuses and asks for a new run.

Scope & interpretation

  • All numbers are computed from deterministic synthetic data. No model is trained.
  • The estimate is an association within the matched sample under the declared policy; it is not a causal effect estimate.
  • Pairs outside the caliper and participants without a partner are excluded and listed, never substituted.
  • Missing outcomes are excluded from the complete-case analysis and handled only in the labelled sensitivity section.
